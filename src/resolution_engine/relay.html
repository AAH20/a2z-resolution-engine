A2Z SOC / Resolution Relay

From proposed answer to reviewed action.

Local operator console for a narrow Zendesk pilot. Answer drafts come from approved knowledge. A separate reviewer previews the current ticket before approval. Public replies are sent only through the existing operator CLI.

Session

The token determines your role and stays in this browser tab's memory. This console binds to localhost and does not offer a send endpoint.

1 · Prepare ticket

Operator fetches one ticket through the configured Zendesk OAuth connector. Unknown or sensitive requests escalate.

2 · Review exact draft

Reviewer must preview the current ticket and its exact draft before approving. Use a separate reviewer token.

Review queue

Metadata only. Ticket text and raw ticket IDs are not stored in the queue. A prepared answer is not a customer resolution.

Enter a token and load the queue.

Send boundary

Approval does not send a reply. A designated sender uses resolution-deploy send, which rechecks the current ticket version and approved answer; uncertain writes require manual reconciliation. No automated retry.
