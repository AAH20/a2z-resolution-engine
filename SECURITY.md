# Security

Report vulnerabilities through GitHub Security Advisories. The built-in API binds to loopback and needs a customer-controlled TLS/identity proxy before remote use. Keep gateway keys, OAuth tokens, customer knowledge, tickets, evaluation labels and SQLite databases out of this public repository. The deployment CLI restricts its Zendesk host to a validated subdomain, stores only keyed ticket hashes and answer hashes, and marks ambiguous writes for manual reconciliation. It does not authenticate knowledge authors or reviewers, verify consent, redact personal data from source input, or establish customer resolution. Obtain those controls before a real pilot.
